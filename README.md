# Демо «Учебный центр» — лендинг для портфолио

Демонстрационный одностраничный сайт учебного центра (ниша: профпереподготовка и повышение квалификации).
Собран как пример структуры для откликов на Kwork (заказчик - учебные центры, курсы, школы).

- Стек: чистый HTML + CSS + JS, сборка Vite
- Дизайн: «учебный лист» - бумага в клетку, пометки красной ручкой, штамп «Зачислено» после отправки формы
- Полностью адаптивен (проверено на 500px и 1440px)

## Запуск локально

```bash
npm install
npm run dev     # http://localhost:7100
npm run build   # сборка в dist/, переложить в docs/ при обновлении
```

Контент вымышленный (центр «Горизонт», Казань) - сайт сделан как демо-пример ниши.
